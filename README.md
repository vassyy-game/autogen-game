# AUTOGEN

Мини-игра про коллекционирование и объединение автомобилей. Игровая логика и изображения работают локально без сборки и игрового сервера; прогресс хранится в `localStorage`. Для интеграции с Telegram загружается Telegram Web Apps SDK с `telegram.org`; если SDK недоступен, игра работает в обычном браузерном режиме.

## Запуск

Откройте `index.html` в современном браузере. Для локального HTTP-сервера из корня проекта можно запустить:

```sh
python3 -m http.server 8000
```

Затем откройте `http://localhost:8000`.

Игра также использует Telegram Web Apps API, если объект `Telegram.WebApp` уже предоставлен средой Telegram; в обычном браузере API не требуется.

## Каталог автомобилей и фотографии

Локальный каталог находится в `assets/cars/catalog.js`, а файлы атрибуции и лицензий — в `assets/cars/catalog.json`. Фотографии хранятся рядом в WebP. Источники, авторы, лицензии и исходные страницы Wikimedia Commons указаны для каждого реально включённого изображения в JSON-каталоге; изображения уменьшены и перекодированы для игры. Покупка автомобиля по-прежнему стоит 1 200 CR; она выбирает случайную модель из доступных локальных изображений. Уже существующие сохранения не мигрируются ради каталога.
