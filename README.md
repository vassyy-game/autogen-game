# AUTOGEN

Мини-игра про коллекционирование и объединение автомобилей. Игра работает без сборки, сторонних библиотек и сетевых запросов; прогресс хранится в `localStorage`.

## Запуск

Откройте `index.html` в современном браузере. Для локального HTTP-сервера из корня проекта можно запустить:

```sh
python3 -m http.server 8000
```

Затем откройте `http://localhost:8000`.

Игра также использует Telegram Web Apps API, если объект `Telegram.WebApp` уже предоставлен средой Telegram; в обычном браузере API не требуется.
